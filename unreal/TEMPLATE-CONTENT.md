# Epic template content

The Unreal branch includes the UE 5.8 Third Person Blueprint template and its
`Characters` and `Input` template dependencies. They provide the first playable
on-foot controller, Quinn mannequin, Enhanced Input mappings, Xbox-compatible
gamepad controls and touch mappings.

Source on the validation PC:

- `Engine/Templates/TP_ThirdPersonBP/Content`
- `Engine/Templates/TemplateResources/High/Characters/Content`
- `Engine/Templates/TemplateResources/High/Input/Content`

These files are Unreal Engine template content and are only intended for use
with Unreal Engine. They are kept separate from GRIDRUNNER's custom hero assets.
